# FundCard (การ์ดตัวเลือกการลงทุน)

## Purpose

การ์ดแสดงตัวเลือกการลงทุนหนึ่งรายการ พร้อมผู้จัดการกองทุน ราคาต่อหน่วย และวันที่ของราคา

## When to use

- หน้ารวมตัวเลือกการลงทุน แสดงเป็นตาราง 2 คอลัมน์บนมือถือ และ 4 คอลัมน์บนจอ 640px ขึ้นไป (story `FundOptions`)
- แสดงตัวเลือกการลงทุนรายการเดียว เช่น แผนปัจจุบันของสมาชิก TODO: ยังไม่มีตัวอย่างการใช้งานนี้ในแอป

## When not to use

- **เปรียบเทียบตัวเลขหลายกองทุน** เช่น ผลตอบแทนย้อนหลัง ค่าธรรมเนียม: การ์ดไม่มีช่องสำหรับข้อมูลเหล่านี้ TODO: ยังไม่มีคอมโพเนนต์ตาราง
- **เป็นปุ่มหรือลิงก์ให้กดเลือก**: การ์ดกดไม่ได้และไม่มีสถานะ hover/เลือก TODO: ยังไม่ได้ตัดสินใจว่าจะทำให้การ์ดกดเลือกได้หรือไม่
- **สินทรัพย์ที่ไม่ได้ซื้อขายเป็นหน่วยหรือไม่ใช่สกุลเงิน AUD**: ราคาแสดงเป็น AUD ต่อหน่วยเสมอ

## Props and variants

ไม่มี variant หรือ size การ์ดกว้างเต็มพื้นที่ที่วาง

| Prop        | ค่า             | บังคับ | ความหมาย                                                                |
| ----------- | -------------- | ---- | ----------------------------------------------------------------------- |
| `name`      | ข้อความ         | ใช่   | ชื่อตัวเลือกการลงทุน เช่น "สมดุล (Balanced)" ชื่อยาวจะขึ้นบรรทัดใหม่                 |
| `manager`   | ข้อความ         | ใช่   | ผู้จัดการกองทุน แสดงเหนือชื่อ ยาวเกินหนึ่งบรรทัดจะถูกตัดด้วย "…"                      |
| `unitPrice` | ตัวเลข          | ใช่   | ราคาต่อหน่วยเป็น AUD แสดงทศนิยม 4 ตำแหน่ง เช่น "AU$1.8342"                    |
| `priceDate` | วันที่            | ไม่   | วันที่ของราคา แสดงเป็น "ต่อหน่วย · ณ วันที่ 13 พ.ย. 2569" ถ้าไม่ใส่ จะเหลือ "ต่อหน่วย" |
| `image`     | `{ src, alt }` | ไม่   | ภาพสี่เหลี่ยมจัตุรัสด้านบน ถ้าไม่ใส่ จะแสดงไอคอนแผนภูมิวงกลมแทน                      |
| `className` | class          | ไม่   | ปรับหน้าตาเฉพาะจุดครั้งเดียว ชนะสไตล์ของการ์ดเสมอ                               |

- `alt` ของภาพเป็นภาษาไทยและบรรยายภาพ เช่น "ภาพประกอบแผนภูมิวงกลม" TODO: ภาพเป็นภาพประกอบเฉย ๆ ควรใช้ `alt` ว่างหรือไม่ ยังไม่ได้ตัดสินใจ
- ชื่อตัวเลือกเป็นหัวข้อระดับ 3 เสมอ TODO: ถ้าโครงสร้างหัวข้อของหน้าไม่ตรง ยังเปลี่ยนระดับไม่ได้
- ใช้ได้เฉพาะในแอป Next.js เพราะภาพแสดงผ่าน Next.js

## Tokens used

ค่าทั้งหมดมาจาก `src/styles/theme.css`

| Token                | โหมดสว่าง                         | โหมดมืด                     | ใช้ใน                                       |
| -------------------- | -------------------------------- | -------------------------- | ------------------------------------------ |
| `--card`             | `oklch(1 0 0)`                   | `oklch(0.228 0.013 107.4)` | พื้นการ์ด                                     |
| `--card-foreground`  | `oklch(0.153 0.006 107.1)`       | `oklch(0.988 0.003 106.5)` | ชื่อและราคา                                  |
| `--foreground`       | `oklch(0.153 0.006 107.1)`       | `oklch(0.988 0.003 106.5)` | เส้นขอบบาง ๆ รอบการ์ด (10%)                  |
| `--muted`            | `oklch(0.966 0.005 106.5)`       | `oklch(0.286 0.016 107.4)` | พื้นที่ภาพ (เห็นเมื่อไม่มีภาพ)                      |
| `--muted-foreground` | `oklch(0.58 0.031 107.3)`        | `oklch(0.737 0.021 106.9)` | ผู้จัดการกองทุน, "ต่อหน่วย · ณ วันที่", ไอคอนแทนภาพ |
| `--radius`           | `0.625rem`                       | –                          | มุมโค้ง (`--radius × 2.2` = 22px)            |
| `--font-heading`     | กำหนดโดยแอป (IBM Plex Sans Thai) | –                          | ชื่อตัวเลือก (16px, medium)                    |

ราคาใช้ 18px น้ำหนัก semibold และตัวเลขความกว้างเท่ากันเพื่อให้เรียงตรงกันในตาราง

## Example

จาก story `FundOptions` ใน `FundCard.stories.tsx` (ตัดเหลือ 2 การ์ด):

```tsx
<div className="mx-auto grid w-full max-w-4xl grid-cols-2 gap-4 sm:grid-cols-4">
  <FundCard
    name="สมดุล (Balanced)"
    manager="เซาเทิร์นครอส อินเวสเตอร์ส"
    unitPrice={1.8342}
    priceDate={new Date(2026, 10, 13)}
    image={{ src: "/funds/balanced.svg", alt: "ภาพประกอบแผนภูมิวงกลม" }}
  />
  <FundCard
    name="ลงทุนอย่างยั่งยืนเพื่อสิ่งแวดล้อมและสังคม (Sustainable ESG Growth)"
    manager="แทสมัน ซัสเทนเนเบิล อินเวสต์เมนต์ส"
    unitPrice={1.5527}
    priceDate={new Date(2026, 10, 13)}
  />
</div>
```
