# Tabs (แท็บ)

## Purpose

สลับดูเนื้อหาหลายส่วนของเรื่องเดียวกันในพื้นที่เดียว โดยแสดงทีละส่วน

## Import and usage

**ตั้งค่าครั้งเดียวในแอป** (ใช้ร่วมกันทุกคอมโพเนนต์):

1. ติดตั้ง `labdsnov` พร้อม `react`, `react-dom` และ `next` (ต้องเป็นแอป Next.js) TODO: ยังไม่ได้เผยแพร่บน npm ตอนนี้ใช้ได้เฉพาะใน monorepo นี้ (`"labdsnov": "workspace:*"`)
2. import สไตล์ครั้งเดียวที่ root layout: `import "labdsnov/styles.css"`
3. กำหนดตัวแปร `--font-heading` (แอปใช้ IBM Plex Sans Thai) และใส่ class `dark` ที่ `<html>` เมื่อต้องการโหมดมืด

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "labdsnov"

;<Tabs defaultValue="overview">
  <TabsList aria-label="ข้อมูลบัญชี">
    <TabsTrigger value="overview">ภาพรวม</TabsTrigger>
    <TabsTrigger value="transactions">ธุรกรรม</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">…</TabsContent>
  <TabsContent value="transactions">…</TabsContent>
</Tabs>
```

- `value` ของ `TabsTrigger` ต้องตรงกับ `value` ของ `TabsContent` ที่คู่กัน
- **ใส่ `defaultValue` (หรือ `value`) เสมอ** เป็นค่าของแท็บที่เปิดได้ ค่าเริ่มต้นคือ `0` ซึ่งไม่ตรงกับ `value` ที่เป็นข้อความ
- ควบคุมแท็บที่เลือกเอง (เช่น เก็บไว้ใน URL) ใช้ `value` กับ `onValueChange` ในไฟล์ที่มี `"use client"`

ถ้าใช้ไอคอน ให้ติดตั้ง `@hugeicons/react` และ `@hugeicons/core-free-icons` ในแอปด้วย

## When to use

- แบ่งข้อมูลของเรื่องเดียวกันเป็นส่วน ๆ ที่ระดับเท่ากัน เช่น บัญชีสมาชิก: ภาพรวม / ธุรกรรม / เอกสาร
- ผู้ใช้ดูทีละส่วนก็พอ ไม่ต้องเปรียบเทียบสองส่วนพร้อมกัน
- ชื่อแท็บสั้น 1–2 คำ ชื่อแท็บไม่ขึ้นบรรทัดใหม่

## When not to use

| สถานการณ์                           | ใช้แทน                                                                   |
| ---------------------------------- | ----------------------------------------------------------------------- |
| ขั้นตอนที่ต้องทำตามลำดับ (ฟอร์มหลายขั้นตอน) | TODO: ยังไม่มีคอมโพเนนต์ stepper                                            |
| ไปหน้าอื่น (แต่ละแท็บมี URL ของตัวเอง)    | ลิงก์ หรือ `NavigationMenu`                                                |
| เปรียบเทียบเนื้อหาสองส่วนพร้อมกัน         | แสดงทุกส่วนในหน้าเดียว                                                      |
| เลือกค่าในฟอร์ม เช่น เลือกแผนการลงทุน    | `RadioGroup` หรือ `Select`                                               |
| แท็บมากจนไม่พอความกว้าง               | ลดจำนวนแท็บ แถบแท็บไม่เลื่อนและไม่ขึ้นบรรทัดใหม่ TODO: ยังไม่ได้กำหนดจำนวนสูงสุดบนมือถือ |

## Anatomy

- **Tabs**: ตัวครอบ เก็บว่าแท็บไหนถูกเลือก
  - **TabsList**: แถบรวมปุ่มแท็บ
    - **TabsTrigger**: ปุ่มแท็บแต่ละอัน
  - **TabsContent**: เนื้อหาของแต่ละแท็บ แสดงเฉพาะแท็บที่ถูกเลือก

## Props and variants

### Tabs

| Prop                      | ค่า                       | ค่าเริ่มต้น      | ความหมาย                                       |
| ------------------------- | ------------------------ | ------------ | ---------------------------------------------- |
| `defaultValue`            | value ของแท็บ             | `0`          | แท็บที่เลือกไว้ตอนแรก                               |
| `value` / `onValueChange` | value ของแท็บ / ฟังก์ชัน     | –            | ควบคุมแท็บที่เลือกจากภายนอก                         |
| `orientation`             | `horizontal`, `vertical` | `horizontal` | `vertical` = แท็บเรียงแนวตั้งด้านซ้ายของเนื้อหา        |
| `className`               | class                    | –            | ปรับหน้าตาเฉพาะจุดครั้งเดียว ชนะสไตล์ของคอมโพเนนต์เสมอ |

### TabsList

| Prop              | ค่า                | ค่าเริ่มต้น   | ความหมาย                                                       |
| ----------------- | ----------------- | --------- | -------------------------------------------------------------- |
| `variant`         | `default`, `line` | `default` | หน้าตาของแถบแท็บ (ดูตารางด้านล่าง)                                  |
| `aria-label`      | ข้อความ            | –         | ชื่อของแถบแท็บสำหรับโปรแกรมอ่านหน้าจอ ใส่เมื่อไม่มีหัวข้อที่บอกว่าแท็บชุดนี้คืออะไร |
| `activateOnFocus` | `boolean`         | `false`   | `true` = เลือกแท็บทันทีเมื่อเลื่อนด้วยลูกศร (ปกติต้องกด Enter หรือ Space)   |
| `loopFocus`       | `boolean`         | `true`    | กดลูกศรเลยแท็บสุดท้ายแล้ววนกลับไปแท็บแรก                              |

| Variant   | หน้าตา                                          | ใช้เมื่อ                        |
| --------- | ---------------------------------------------- | ---------------------------- |
| `default` | แท็บอยู่ในแคปซูลพื้นเทา แท็บที่เลือกเป็นแคปซูลสีพื้นหลังยกขึ้นมา | TODO: ยังไม่ได้กำหนดเกณฑ์การเลือก |
| `line`    | ไม่มีพื้น แท็บที่เลือกมีเส้นใต้ (แนวตั้ง: เส้นด้านขวา)        | TODO: ยังไม่ได้กำหนดเกณฑ์การเลือก |

แถบแท็บแนวนอนสูง 36px กว้างเท่าที่แท็บต้องการ ตัวอักษร 14px น้ำหนัก medium ไอคอน 16px

### TabsTrigger

| Prop       | ค่า        | ความหมาย                          |
| ---------- | --------- | --------------------------------- |
| `value`    | ข้อความ    | **บังคับ** ค่าที่ใช้จับคู่กับ `TabsContent` |
| `disabled` | `boolean` | ปิดใช้งาน จางลง 50% เลือกไม่ได้        |

วางไอคอนหน้าหรือหลังชื่อแท็บได้ตาม story `WithIcons`

### TabsContent

| Prop          | ค่า        | ค่าเริ่มต้น | ความหมาย                                                               |
| ------------- | --------- | ------- | ---------------------------------------------------------------------- |
| `value`       | ข้อความ    | –       | **บังคับ** ตรงกับ `value` ของ `TabsTrigger`                               |
| `keepMounted` | `boolean` | `false` | เก็บเนื้อหาแท็บที่ไม่ได้เลือกไว้ในหน้า (ซ่อนไว้) แทนการเอาออก เช่น ฟอร์มที่ต้องจำค่าที่กรอก |

### พฤติกรรมที่มีให้แล้ว

- กด Tab แล้วโฟกัสไปที่แท็บที่เลือกอยู่ ลูกศรซ้าย/ขวา (แนวตั้ง: ขึ้น/ลง) เลื่อนโฟกัสระหว่างแท็บ Home/End ไปแท็บแรก/สุดท้าย และ Enter หรือ Space เลือกแท็บ
- เนื้อหาแท็บที่ไม่ได้เลือกถูกเอาออกจากหน้า เว้นแต่ใส่ `keepMounted`
- **Focus จากคีย์บอร์ด**: แท็บมีวงแหวนทึบสี `--focus-ring`

## Tokens used

ค่าทั้งหมดมาจาก `src/styles/theme.css`

### Component tokens

token เฉพาะของคอมโพเนนต์นี้ ชี้ไปที่ semantic token ด้านล่าง เปลี่ยนที่นี่เพื่อปรับเฉพาะคอมโพเนนต์นี้ (โหมดมืด "–" = ใช้ค่าเดียวกับโหมดสว่าง)

| Token                      | โหมดสว่าง             | โหมดมืด    | ใช้ใน                                          |
| -------------------------- | -------------------- | --------- | --------------------------------------------- |
| `--tabs-trigger-fg`        | `--muted-foreground` | –         | ตัวอักษรแท็บที่ไม่ได้เลือก                            |
| `--tabs-list-bg`           | `--muted`            | –         | พื้นแคปซูล (`default`)                           |
| `--tabs-trigger-active-fg` | `--foreground`       | –         | ตัวอักษรแท็บที่เลือก และตอน hover                   |
| `--tabs-trigger-active-bg` | `--background`       | `--input` | พื้นแท็บที่เลือก (`default`)                        |
| `--tabs-indicator`         | `--foreground`       | –         | เส้นใต้แท็บที่เลือก (`line`)                        |
| `--focus-ring`             | `--ring`             | –         | วงแหวน focus จากคีย์บอร์ดของทุกคอมโพเนนต์ (ทึบ 2px) |

### Semantic tokens

| Token                | โหมดสว่าง                   | โหมดมืด                     | ใช้ใน                                                     |
| -------------------- | -------------------------- | -------------------------- | -------------------------------------------------------- |
| `--muted`            | `oklch(0.966 0.005 106.5)` | `oklch(0.286 0.016 107.4)` | พื้นแถบแท็บ (`default`)                                     |
| `--muted-foreground` | `oklch(0.5 0.027 107.3)`   | `oklch(0.737 0.021 106.9)` | ชื่อแท็บที่ไม่ได้เลือก (โหมดมืด)                                  |
| `--foreground`       | `oklch(0.153 0.006 107.1)` | `oklch(0.988 0.003 106.5)` | ชื่อแท็บ (60% เมื่อไม่ได้เลือก), hover, แท็บที่เลือก, เส้นใต้ `line`   |
| `--background`       | `oklch(1 0 0)`             | `oklch(0.153 0.006 107.1)` | พื้นแท็บที่เลือก (`default`, โหมดสว่าง)                         |
| `--input`            | `oklch(0.93 0.007 106.5)`  | `oklch(1 0 0 / 15%)`       | พื้นแท็บที่เลือก (`default`, โหมดมืด 30%)                       |
| `--ring`             | `oklch(0.45 0.03 106.9)`   | `oklch(0.8 0.02 106.9)`    | วงแหวน focus                                             |
| `--radius`           | `0.625rem`                 | –                          | แนวตั้งใช้มุมโค้ง `--radius × 1.8` = 18px (แนวนอนเป็นทรงแคปซูล) |

## Example

จาก story `WithIcons` ใน `Tabs.stories.tsx`:

```tsx
<Tabs defaultValue="overview">
  <TabsList>
    <TabsTrigger value="overview">
      <HugeiconsIcon
        icon={PieChartIcon}
        strokeWidth={2}
        data-icon="inline-start"
      />
      ภาพรวม
    </TabsTrigger>
    <TabsTrigger value="transactions">
      <HugeiconsIcon
        icon={Exchange01Icon}
        strokeWidth={2}
        data-icon="inline-start"
      />
      ธุรกรรม
    </TabsTrigger>
    <TabsTrigger value="documents">
      <HugeiconsIcon
        icon={File01Icon}
        strokeWidth={2}
        data-icon="inline-start"
      />
      เอกสาร
    </TabsTrigger>
  </TabsList>
</Tabs>
```
